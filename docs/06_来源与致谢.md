# 来源与第三方说明

本仓库（YI-PPT）自身按 [Apache-2.0](../LICENSE) 发布。它不包含也不再分发下列工具，只描述如何配合使用；各工具的许可以其官方为准，使用前请自行阅读，尤其是在公司或商业场景中。

| 项目 | 用途 | 许可提示 |
| --- | --- | --- |
| [Remotion](https://www.remotion.dev/) | 全部动效的渲染 | 不是 OSI 意义上的开源许可；对公司使用有商业条款，使用前请阅读官方 license 页面 |
| [FFmpeg](https://ffmpeg.org/) | 切片、转码、自检 | LGPL 或 GPL，取决于你安装的构建 |
| [pptxgenjs](https://gitbrent.github.io/PptxGenJS/) | 在 deck 工程里生成 pptx（可换成宿主自带的 pptx 能力） | MIT |
| Recordly 或其他录屏工具 | 录制产品操作（按需） | 以所用工具的官方许可为准 |
| Microsoft PowerPoint | 放映与最终验收 | 商业软件，需自行持有授权 |

## 参考

- DESIGN 文件的格式参考 [google-labs-code/design.md](https://github.com/google-labs-code/design.md)：JSON front matter 放参数，正文解释用途；`x-deck` 是本仓库的扩展。
- `tools/` 里的三个脚本为本仓库原创实现，只依赖 FFmpeg／FFprobe 与 Python 3 标准库。
- `tools/samples/接缝测试.pptx` 由 pptxgenjs 生成，仅含色块测试画面。
