# 建立 DESIGN

三段分开发，不跳过静态与动态确认。

## 第一步：静态样页

```text
读取 AGENTS.md、docs/05_DESIGN建立.md 和 templates/DESIGN.template.md，准备本系列静态样页。
内容类型与受众：[填写]
想要的观感：[填写]　不喜欢的观感：[填写]
放映场景：[投影／会议共享]
参考图及各自用途：[路径；分别说明借鉴配色、构图、图形或字体]

用同一段中性内容做 2～3 个有实质区别的方案，每个方案包含一张视频页落点（Remotion 静帧）和一张原生页（pptx）。
保留可编辑参数，候选放到 00_系列测试/静态/，告诉我重点比较什么。这一步不写正式 DESIGN。
```

## 第二步：动态样章

```text
静态方案采用：[路径与确认范围]。
用该方案做一段 3～5 个 beat 的样章：覆盖对象变形、一次镜头推进或拉开、每个 beat 的停稳落点。
动态偏好与参考：[填写；没有就提出少量可比较的方案]

整章渲染 → split-beats 切片 → 组装成 pptx（叠 hold-last 末帧图）→ pptx-autoplay --hold-last，交给我在放映电脑上试放。
跑动态自检，说明每个 beat 解决什么判断。源码与产物放到 00_系列测试/动态/，结果先作为候选。
```

## 第三步：写入规范

```text
我确认以下样本：[静态文件、动态样章、试放结果，以及各自确认的方面]。
按 templates/DESIGN.template.md 整理根目录 DESIGN-[风格名].md：从确认样本提取颜色、字体、间距、圆角、组件、PPT 版式、运动曲线、beat 停稳帧数与校准数据，记录样本路径与确认范围。
没验证过的保持待定，不补默认值。修改已有的 DESIGN 文件时先保留原版，只改这次确认覆盖的部分。
同时给出 Remotion 的 design.ts 和 PPT 主题的取值，说明仍需测试的内容。
```

成功标志：`DESIGN-<风格名>.md` 能找到对应的真实样页、样章与试放记录，没有把候选或单章参数扩大成系列默认。
