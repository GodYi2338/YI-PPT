# 目录与工程

## 目录

```text
系列根目录/
  AGENTS.md  DESIGN-<风格名>.md        # 可有多份；静态与动态样本确认后建立（可从 examples/ 复制起步），每份 deck 由用户选定一份
  docs/ templates/ prompts/ tools/
  00_系列测试/                         # 静态样页、动态样章与确认记录
  01_公共资产/                         # 字体、Logo、可复用 Remotion 组件、PPT 主题
  D01_主题/                            # 一份 deck
    00_控制/                           # 页面表.md、QA表.md
    01_内容/                           # 大纲、讲稿、资料
    02_设计/                           # 动线剧本.md、关键帧/、视觉总览
    03_素材/                           # 录屏原片、图片、来源.md
    04_动效工程/                       # Remotion 工程
    05_PPT/                            # build_deck 脚本、生成的 pptx
    06_交付/                           # 最终 pptx、备份版、可选整片 mp4
    90_历史/                           # 被替代的版本
```

按实际阶段补目录，不建空文件冒充进度。尚无 deck 目录且没给名字时，按主题取临时名。

## Remotion 工程约定

```text
04_动效工程/
  src/
    Root.tsx                 # 每章注册一个 Composition：id 为 C01、C02…
    design.ts                # 取值以选定的 DESIGN 文件为准，不手抄第二份
    chapters/C01/
      index.tsx              # 本章时间轴
      beats.json             # [{"id":"P03","start":0,"end":96}, …] 唯一的 beat 帧号来源
  public/                    # 录屏、图片等素材
  renders/                   # C01_v01.mp4、C01_v01_beats/（切片输出）
  _work/                     # 自检输出等临时文件
```

- 画布与帧率按选定的 DESIGN 文件；默认 1920×1080，帧率在样章里确认后固定，不在章间混用。
- `beats.json` 的 `id` 用页面表里的页号（如 P03），切片输出的文件名与之对应。帧号从 0 开始，`end` 不包含。
- 章内动画按 beat 起点计算时间，例如 `interpolate(frame, [b.start + 6, b.start + 40], …)`。改一个 beat 的时长只改 `beats.json`，后面的 beat 跟着移动，不逐个改动画帧号。
- 每章的末尾 beat 也要停稳；下一章或原生页从“切”开始。

常用命令（在 `04_动效工程/` 下运行，参数以所装 Remotion 版本的文档为准）：

```bash
npx remotion still C01 ../02_设计/关键帧/P03.png --frame=95
npx remotion render C01 renders/C01_v01.mp4 --codec=h264 --crf=12
../../tools/split-beats.sh renders/C01_v01.mp4 src/chapters/C01/beats.json renders/C01_v01_beats 12
../../tools/motion-check.sh renders/C01_v01.mp4 _work/motion-check/C01_v01
```

整章渲染用较高质量（低 crf），切片时再统一转成放映用的 H.264；规格见 [tools/README.md](../tools/README.md)。

## PPT 构建约定

```text
05_PPT/
  build_deck.js              # 唯一的 PPT 来源：页序、页型、原生内容、视频路径、备注
  D01_v03.pptx               # 构建输出（未设自动播放）
  D01_v03_auto.pptx          # pptx-autoplay 处理后，交用户放映的版本
```

- 构建脚本按页面表的页序生成，视频页引用 `renders/<章>_vNN_beats/<页号>.mp4` 与对应的 `_first.png`。
- 用户在 PowerPoint 里改过的文件交回后，Agent 读出改动写回 `build_deck.js`，再重新生成；不同时维护两个来源。
- 版本号随内容变化递增，旧版本移到 `90_历史/`。

## 公共资产

复用前去掉某一份 deck 的文案、路径和帧号，把差异做成参数，并说明验证过的范围。更新公共资产不自动改写已完成的 deck。
