# 页面表与动线剧本

## 出页面表

```text
读取 AGENTS.md、docs/01_工作流.md 和 templates/页面表.template.md。
本份 deck：[目录路径]；内容依据：[确认的大纲或讲稿路径]；DESIGN：[从根目录 DESIGN-*.md 中选定的文件；未选时 Agent 先列出请我选]。
总页数或时长预期：[填写或不限]。

按内容划页，再按“这一下观众要多看懂什么”划 beat；每页定页型（视频／原生／混合），把连续视频页归入章。
写清各页的主角对象与落点、对标章或新类型、页与页之间的衔接方式。
附重点审查表，并在聊天里指出最值得我先看的 3 个问题。写入 00_控制/页面表.md。
```

确认时可以直接说：“确认这版页面表的划分与页型，按此写动线剧本。”

## 写动线剧本

```text
页面表 v[__] 已确认。读取 templates/动线剧本.template.md。
为所有章一次写完动线剧本：主角对象怎样跨 beat 连续变化、镜头怎样带人看、每次点击后停在哪里讲、章的进入和交出。
按“排时间”估计每个 beat 的动效时长，过长的拆 beat 并同步建议修改页面表。
写入 02_设计/动线剧本.md，交我审一次；确认前不出关键帧。
```
